# Contributing to AgentOffice

Open an issue with your operating system, Node.js version, and the steps to reproduce the problem. Use `?demo` or synthetic fixtures when sharing screenshots and logs.

For a pull request, follow the [local setup](README.md#run-locally), run `npm run check` and `npm run build`, and describe what you verified.

Keep the server on loopback and the collectors read-only. Session actions require an explicit dashboard action. Keep transcript excerpts short and redacted, and use local assets for the interface.
